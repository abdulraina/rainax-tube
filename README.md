# RAINAX Tube website

Download page for the RAINAX Tube Android app.

- `index.html` is the whole site (one file, no build step).
- The Download button always gives the newest APK from the app's latest GitHub release:
  https://github.com/raowaheedbhkpk-dev/rainax-yt-downloader/releases/latest/download/RAINAX.apk

Hosted on Render as a Static Site: Build Command empty, Publish Directory `.`
